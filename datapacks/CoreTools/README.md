# CoreTools

Датапак и ресурспак для расширенного взаимодействия с инструментами в Minecraft.

## Возможности
- **3x3 Mining Hammer:** Молот для раскопки блоков областью 3x3.
- **Tree Capitator (LMB Chop):** Быстрая рубка деревьев топором.
- **Быстрая обтёска бревен (Strip):** Обтёска области древесины 3x3.

## Структура версий
- `1.21.1/` — Minecraft 1.21 - 1.21.1 (Data Pack format `48`, Resource Pack format `46`)
- `1.21.5/` — Minecraft 1.21.5 (Data Pack format `71`, Resource Pack format `46`)
- `26+/` — Minecraft 26+ (Data Pack format `121`, Resource Pack format `97`)
- `26.3/` — Minecraft 26.3 с поддержкой новых типов древесины (Poplar)
