# Ghast Speed Datapack (Minecraft 26.3)

Датапак, позволяющий гастам (`minecraft:ghast`) и счастливым гастам (`minecraft:happy_ghast`) корректно ускорять полёт при получении эффекта **Скорость** (`minecraft:speed`).

## Отличия и преимущества перед старыми версиями (до 26.3)

1. **Совместимость с Minecraft 26.3**:
   - `pack.mcmeta` настроен под современный формат пакетов данных (`min_format: [121, 0]`, `max_format: [121, 0]`, `pack_format: 121`).
   - Использован актуальный синтаксис атрибутов `minecraft:flying_speed` и модификаторов с именованными идентификаторами (`ResourceLocation`).

2. **Полностью оригинальный код без заимствований**:
   - В отличие от референса с 226 сгенерированными предикатами и громоздкой функцией, написана чистая и лаконичная архитектура на макросах (`macro functions`) и вычислениях.

3. **Не ломает базовые атрибуты**:
   - Вместо принудительной перезаписи `attribute ... base set`, датапак использует модификатор `attribute ... modifier add ... add_multiplied_base`. Базовая скорость моба сохраняется нетронутой.

4. **Точное соответствие механике ванильного эффекта**:
   - Каждый уровень Скорости даёт ровно **+20%** к скорости полёта:
     - Скорость I: +20%
     - Скорость II: +40%
     - Скорость III: +60%
     - Динамически поддерживает любые уровни зелий (вплоть до 255).

5. **Высокая производительность (0 тиковых лагов)**:
   - Модификатор обновляется только в момент наложения эффекта или смены уровня зелья.
   - Если моб без эффекта Скорости — никакие вычисления не производятся.
